1. x2eq - Takes the a, b and c values from a quadratic equation and computes the roots.
It has a way of delivering the results that I personally find very useful. 
 
```
algopro-ii $ ./x2eq 1 -4 -16
4 +- sqrt(80) / 2
x' = 6.47
x" = -2.47
algopro-ii $ ./x2eq 2 -4 -16
(4/1) | (-2/1)
x' = 4.00
x" = -2.00
```
